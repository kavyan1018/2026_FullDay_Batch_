=========================================
COMPILE TIME POLYMORPHISM TASKS IN C++
=========================================

1. Function Overloading - Area Calculator
-----------------------------------------
Create a class Area with overloaded area() functions:
- area(int side)          -> Area of Square
- area(int l, int b)      -> Area of Rectangle
- area(float radius)      -> Area of Circle

=========================================

2. Function Overloading - Sum Calculator
----------------------------------------
Create overloaded sum() functions:
- Sum of 2 integers
- Sum of 3 integers
- Sum of 2 float numbers

=========================================

3. Function Overloading - Employee Details
------------------------------------------

- Display employee name
- Display employee name and salary
- Display employee name, salary, and department

=========================================

4. Function Overloading - Volume Calculator
-------------------------------------------
