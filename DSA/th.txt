complexity  
    
    -> it means the amount of resources (time and space) required by an algorithm to solve a problem as a function of the size of the input.



time complexity -> it refers to the amount of time an algorithm takes to complete..
time complexity = O(n) -> linear time complexity, that means the algorithm's running time increases linearly with the input size.

space complexity -> it refers to the amount of memory an algorithm uses to complete.
space complexity = O(1)  -> constant space complexity, that means the algorithm uses a fixed amount of memory regardless of the input size.
